
# Приложение для анализа банковских операций

# Описание функционала приложения

## Проект состоит из следующих функций:

### Главная страница

-   `VIEWS`: Приветствует пользователя в соответствии с его текущим временем суток. Принимает от пользователя дату, и возвращает ответ по каждой карте с общей суммой расходов и кешбэк. 
Выводит топ 5 транзакций по сумме платежа, курс валют и стоимость акций. 
### Сервисы

-   `SERVICES`: Дает анализ по выгодным категория кешбэка. 
### Отчеты

-   `REPORTS`: Выводит средние траты за последние 3 месяца от указанной даты, по каждому дню недели. 
## Установка

Для установки и запуска проекта необходимо выполнить следующие шаги:

1.  **Клонируйте репозиторий:**

    ```
    git clone git@github.com:Klimchuk-sergei/kursovaya_work.git
    ```

2.  **Откройте проект**

   

3.  **Установите зависимости с помощью Poetry:**

    ```
    poetry install
    poetry add --group lint flake8
    poetry add --group lint mypy
    poetry add --group lint black
    poetry add --group lint isort
    poetry add --group dev pytest
    poetry add --group dev pytest
    poetry add pandas 
    ```

## Использование

Запустите файл main.py.  
Вы получаете Json ответ, который был получен из данных содержащихся в EXEL файле, находящемся в папке DATA.





## Тестирование

В проекте используются тесты, написанные с использованием `pytest`. Для запуска тестов выполните следующие шаги:

1. **Убедитесь, что установлены все зависимости (см. раздел "Установка").**
2. **Активируйте виртуальное окружение Poetry:**

~~~
    poetry env activate   
~~~
3. **Запустите тесты с помощью команды `pytest`:**

~~~
    pytest tests   
~~~
